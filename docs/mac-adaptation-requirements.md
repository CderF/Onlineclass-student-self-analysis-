# macOS 适配需求文档

> 整理日期：2026-11-05

## 一句话定位

让程序在 macOS 上的窗口外观、窗口行为和菜单栏符合 mac 习惯；Windows 上保持现状。

## 现状（调查结果）

- 右上角的红黄绿三个按钮其实是 **macOS 原生按钮**；qfluentwidgets 自带的 Windows 风格按钮在 macOS 上已经隐藏。
- 按钮出现在右上角，是 qfluentwidgets 的设计：`FluentWindowBase.systemTitleBarRect` 把系统按钮区域固定在窗口右侧（`size.width() - 75`）。原因是左上角已经放了导航栏的 ←（返回）和 ☰（展开 / 收起侧边栏），这一列宽 48px，而红黄绿约需 75px。
- 菜单栏由 Qt 自动生成，只有一个英文的应用菜单（About〈脚本名〉、About Qt、Settings… ⌘,、Services、Hide、Hide Others、Show All、Quit ⌘Q），没有ウインドウ菜单和編集菜单。用 `python main.py` 启动时，菜单栏加粗的程序名显示为 python。
- 绿色按钮进入系统全屏。双击标题栏由 qframelesswindow 处理，固定为最大化 / 还原，不读取系统设置。

## 已确认的需求

### 1. 范围与平台

- 只改 macOS 上的外观和行为，按 `sys.platform` 分支处理。
- Windows 保持现状：右上角按钮不变，不加菜单栏，也不加新的快捷键。

### 2. 左上角布局（mac）

- 红黄绿、←、☰ 排在左上角**同一行**（类似 Safari 工具栏）。
- 侧边导航（モニター / 分析レポート）从第二行开始。

```
┌────────────────────────────┐
│ ● ● ●  ←  ☰                │
│ 📷   ┌────────────────────┐│
│ 📊   │   页面内容         ││
│      │                    ││
└──────┴────────────────────┘┘
```

### 3. 窗口行为（mac）

- 绿色按钮：进入系统全屏；按住 Option 点击为缩放。
- 双击标题栏：按「系统设置 → 桌面与程序坞 → 连按窗口标题栏以」执行（缩放 / 最小化 / 不执行任何操作）。
- 全屏时，← 和 ☰ 仍正常显示、可用。
- 关闭：红色按钮、⌘W、⌘Q 都**直接退出程序**，课程记录的保存流程（`MainWindow.closeEvent` → `stop()`）不变。

### 4. 菜单栏（mac，日语）

- 程序名：**Self-Analysis**（菜单栏加粗名称、「…について」「…を終了」中使用）。窗口标题仍为「学習エンゲージメント自己分析」。
- **应用菜单**：Self-Analysisについて、サービス、Self-Analysisを隠す ⌘H、ほかを隠す ⌥⌘H、すべてを表示、Self-Analysisを終了 ⌘Q。去掉「設定…」和「About Qt」。
- **ウインドウ**：しまう ⌘M、拡大/縮小、フルスクリーンにする ⌃⌘F、閉じる ⌘W。
- **編集**：取り消す、カット、コピー、ペースト、すべてを選択。作用于课程名输入框和报告页中的文字。
- **表示**：モニター ⌘1、分析レポート ⌘2、显示 / 隐藏侧边栏。
- **关于面板**：用 macOS 标准关于面板，显示程序名、版本号和一句日语说明（研究用原型，数据只保存在本机）。版本号从 **0.1.0** 起，集中放在代码中一处管理。

### 5. 实现约束

- **不修改第三方库**（qfluentwidgets / qframelesswindow 的 site-packages 源码），只在本项目代码里通过子类和重写来覆盖。发现某项只有改库才能实现时，先单独确认。
- 如果直接使用 pyobjc（例如修改菜单栏中的程序名），要在 `requirements.txt` 中加上只在 darwin 生效的版本锁定。目前 pyobjc 只是 PyQt5-Frameless-Window 的间接依赖。

### 6. 验收

- **自动验证**：
  - 能在 offscreen 下测的部分写 pytest。
  - 真实窗口相关的写 `test-scripts/verify_issue<N>_*.py`，用原生平台运行，检查红黄绿与 ← ☰ 的位置、菜单项与快捷键、全屏与双击行为。注意：`MainWindow` 在 offscreen 下会 segfault，见 `CLAUDE.md`。
- **mac 手动检查清单**：随实现一起提供，由作者确认观感。
- **Windows 回归**：由作者在自己的 Windows 电脑上手动确认外观和行为没有变化。

## 明确不做

- 跟随系统深色模式。
- 打包成 `.app`（Dock 图标、程序名、摄像头权限说明）。
- 关闭窗口后程序仍留在 Dock 中。
- 把监控的开始 / 暂停 / 停止放进菜单栏或加快捷键。
- 修改、fork 或替换 qfluentwidgets / qframelesswindow。

## 待定项

无。Windows 端的回归确认由作者在实现完成后进行。
