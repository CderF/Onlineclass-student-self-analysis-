# test-scripts

专项验证脚本：覆盖 `tests/`（pytest）不便模拟的情况，如真实进程崩溃、并发读写、长时间运行、性能，以及需要真实摄像头或人工观察的场景。

- 在仓库根目录用 `demo` 环境运行：`python test-scripts/<脚本名>.py`
- 退出码 0 表示全部通过；每个检查项打印 `PASS` / `FAIL`
- 临时数据写在系统临时目录，不碰 `data/`

| 脚本 | 对应 Issue | 内容 |
|---|---|---|
| `verify_issue3_storage.py` | #3 | 真实分析器场景下的每秒汇总重算、SIGKILL 崩溃恢复、并发读写、90 分钟性能与体积 |
| `verify_issue4_recording.py` | #4 | 原生平台真实窗口端到端（按钮、课程名对话框、暂停中关窗口）、时间轴核算、真实程序 SIGKILL 后重启；`--real-camera` 为人工验证模式 |
| `verify_issue5_report.py` | #5 | 原生窗口点侧栏打开报告页显示示例数据并截图、记录一节课后立即可见、90 分钟课程的显示耗时、离线（无网络请求）、真实程序打开报告页后退出 |
| `verify_issue6_session_chart.py` | #6 | 真实记录后图表与数据库独立重算一致、90 分钟课程逐区间取色核对、真实 Qt 鼠标 / 滚轮事件下的悬停提示与四行缩放联动 |
| `verify_issue7_problem_segments.py` | #7 | 与独立朴素实现在 300 节随机课程上逐一比对及不变量检查、判定耗时、真实记录离席被判为问题时段、60 分钟示例的问题时段行与曲线底色取色核对、真实鼠标悬停 |
| `verify_issue8_summary.py` | #8 | 25 节示例课程独立重算后与汇总图表及课程别汇总表逐一比对、真实记录后出现在汇总中、真实 Qt 鼠标点击列跳转与点击表格行筛选、空心点取色、60 节 90 分钟课程的汇总耗时 |
| `verify_issue9_feedback.py` | #9 | 2000 个随机输入的不变量检查（含独立重算总评分档）、真实记录同课程名两节课后的反馈与前回比较、真实鼠标点击时段缩放曲线、60 节历史下的读取耗时；输出多场景反馈文本 `feedback_samples.txt` 供审阅措辞 |
| `verify_issue15_resume_timeline.py` | #15 | 真实 CameraThread 随机时机暂停 / 继续、首帧随机延迟 0–2 秒（含首帧前再次暂停），核对时间轴连续、继续点 = floor(暂停点)+1、等待首帧计入暂停；修复前的代码在此脚本上会失败 |
